# Work Daily Report

把一组工作日常记录整理成中文 Markdown 周报、月报或年终总结。**本 SKILL 是结构与规则的唯一权威**：调用方只负责喂输入变量，不要再额外塞强制结构。

记录分两个大类：**工作**（公司业务平台）和**学习**（个人学习、技术探索类平台）。两类内容在报表里**分块写，不混排**。「个人」大类不在本报表里，由另一份个人成长记录负责。

## Input

调用方提供：

- `title`：报表标题（如 `牛马日常月报 - 2026-05`）。
- `type`：`week` / `month` / `year`。
- `report_type_label`：`周报` / `月报` / `年报`。
- `style`：本次报表的风格提示（详见下方 Type Style）。
- `platform_count` / `record_count`：本阶段平台数、记录数（工作 + 学习合计）。
- `work_platforms`：工作大类的平台名列表；`无` 表示本阶段没有工作记录。
- `study_platforms`：学习大类的平台名列表；`无` 表示本阶段没有学习记录。
- `source`：原始记录，先按大类（`# 工作` / `# 学习`）、再按平台（`## 平台名`）分组，每条 `- {date}: {content}`。
- `previous_summary`（可选）：上一期同类型报表的「概览」段（年报为「写在前面」段）。**未提供时整篇不得出现任何"相比上期 / 环比 / 去年"之类的对比措辞。**

## Output：周报 / 月报

**直接输出 Markdown，不要用 ``` 或 ```markdown 把整篇报表包起来**。`type` 为 `week` / `month` 时按以下顺序：

```markdown
# {title}

## 🏝️ 概览

{用 80-180 字说明这是一份 {report_type_label}，本阶段工作主要投入在哪些平台、学习上在钻研什么，形成了哪些产出。若提供 previous_summary，在末尾用 1-2 句点出与上期的延续或变化。}

## 🥬 数据速览

| 指标 | 数值 |
| --- | --- |
| 覆盖平台 | {platform_count} 个 |
| 记录条数 | {record_count} 条 |
| 活跃天数 | {source 里去重后的日期数} 天 |
| 关键交付 | {记录中出现的 PR / commit / issue 引用条数} 项 |

## ✨ 本阶段亮点

> 1. **{关键词}**：{一句话，挑产出密度或影响面最大的事}
> 2. **{关键词}**：{一句话}

## ✈️ 工作平台总结

### {工作平台名称}

- **{动词开头}**{合并后的工作产出，每条一句话、控制在一行内（约 45 字），3-6 条，不逐条复述原始记录}

## 📚 学习总结

### {学习平台名称}

- **{动词开头}**{学了什么、做出了什么，每条一句话，2-5 条}

## 🌱 学习收获

- {2-5 条，从工作和学习记录中提炼学到的方法、框架、业务理解或工程经验}

## 🦴 需要加强

- {2-5 条，从记录中看出的知识短板、能力短板或后续要补齐的方向}

## 🗺️ 下一阶段计划

- [ ] {2-5 条，checklist 格式，基于当前记录自然推出的下一步计划；如果原始记录不足，只写稳妥的延续动作，不编造具体项目}

## 🌙 结束语

{1-2 句，第一人称视角自然收尾，语气务实。}
```

## Output：年终总结

`type` 为 `year` 时改用年终总结结构，按以下顺序：

```markdown
# {title}

## 🎐 写在前面

{150-300 字，抒情一点：先写一年走过来的感慨（忙在哪里、哪几段日子印象深），再写对新一年的期盼。情绪要落在记录里真实发生过的事情上，不空喊口号、不堆排比。若提供 previous_summary，可以用一句话呼应去年的状态。}

## 🥬 数据速览

{同周报 / 月报的数据速览表}

## ✈️ 这一年的工作

### {工作平台名称}

- **{动词开头}**{这一年在该平台的主要成果，3-6 条}

## 📜 关键项目时间线

- {月份/季度}：{里程碑}（3-8 条，工作和学习里的重要节点都可以放）

## 📚 这一年的学习

### {学习平台名称}

- **{动词开头}**{这一年学了什么、做出了什么、学到什么程度，2-5 条}

## 🌟 越用越顺手的地方

- **{技术或方法}**：{2-5 条。写这一年哪些技术、工具、方法用得明显更熟练了（例如缓存、队列、异步任务的应用更加顺手），以及哪些新接触的东西比旧做法更好、好在哪里。必须能在记录里找到对应的事}

## 🦴 不足与反思

- {2-5 条。写哪些地方做得不够好，哪些问题如果换一种方法会处理得更好；每条尽量点出「当时怎么做的」和「更好的做法可能是什么」}

## 🗺️ 新一年近期计划

- [ ] {3-6 条 checklist，写近期能落地的计划。如果记录显示某些功能主要靠 AI 完成，要写出需要补强的地方（例如代码阅读、原理理解、调试能力），做到不只是能用，还能看懂、能改、能排错}

## 🌙 结束语

{1-2 句，第一人称，收住全文。}
```

## Rules

### 结构与排版
- 恰好一个 H1；H1 与 `title` 完全一致，**H1 不加图标**。
- H2 节标题和图标**固定如上**，不增减、不替换；周报 / 月报与年终总结各用各的结构，不要混用。
- 工作平台只出现在「工作平台总结 / 这一年的工作」里，学习平台只出现在「学习总结 / 这一年的学习」里，**两类不混写到同一节**。
- `study_platforms` 为 `无` 时省略「📚 学习总结 / 📚 这一年的学习」整节；`work_platforms` 为 `无` 时省略「✈️ 工作平台总结 / ✈️ 这一年的工作」整节。
- 平台 H3 **不加图标**；同名平台合并，不重复出现 H3。
- 平台 H3 **按本阶段产出密度从多到少排序**（字数或记录条数权衡），主力平台在前；条目尽量以**加粗动词**开头（如 **重构**、**修复**、**打通**）。
- 月报 / 年报的工作节里，产出很少的平台（记录 ≤ 2 条）合并为一个 `### 其他平台` 小节，每个平台 1 条要点，避免长报表小节过碎。
- 「本阶段亮点」2-3 条，blockquote 编号列表，关键词加粗；与平台总结允许内容重叠，但不要原句重复。
- 「数据速览」**只能从输入统计**：活跃天数 = `source` 去重日期数；关键交付 = 记录里 PR / commit / issue 引用条数。某指标统计不出来就**整行省略**，不写 0、不猜。
- 计划类小节用 `- [ ]` checklist 格式，方便直接复制进待办列表。
- 不要用 ``` 包裹整个输出；正文里原有的代码块、文件路径、PR 编号、commit hash 等原文标识**保持原样**，不要改写或删掉。
- 不要逐条复述原始记录；不要逐日罗列日期。
  - 周报：允许在平台总结或学习收获里点出 1-2 个关键节点的具体日期（发布日、踩坑日等）。
  - 月报 / 年报：不出现具体日期，只说本月 / 本年（年报时间线里的月份 / 季度除外）。

### 内容真实性
- 收获、加强、顺手、不足、计划等推断类内容**只能从提供的记录中推导**，不编造记录外的具体项目、人名、数据、收益数字。
- 年终总结「写在前面」的抒情只能抒记录里真实存在的事，不虚构经历、情景和人物。
- PR 编号（如 `blog#20`）、commit hash、issue 链接是后续追溯的关键索引，至少在平台总结对应条目里保留一次。
- 对比叙述**仅当提供 `previous_summary` 时**出现，且只比较两期都明确提到的事实；禁止编造增减幅度或数字。

### 记录较少时的精简策略
- 当 `record_count < 3`：精简为「概览（年报为写在前面）+ 平台总结（工作 / 学习节按有无输出）+ 🌙 结束语」，其余节全部省略，不要硬凑。
- 当某一项实在推不出来（如本周纯运维、无新学习点）：该段写一句兜底，如「本阶段以稳定运维 / 迭代为主，未触发新的能力短板」，不要编造；「本阶段亮点」推不出 2 条就省略整节。

### 结束语防泄漏（高频翻车区，专门强调）
- 结束语**严禁出现**：「AI」「模型」「本次总结」「报表」「以上是…」「根据您提供的」「希望对您有帮助」「如有需要…」「让我们…」等元描述或客套语。
- 结束语用**第一人称**（我），不要写「用户」「您」。
- 不要在正文任何地方提到 skill、prompt、模型、生成流程；如果原始记录里写到「使用 skill」「整理 prompt」等，请用「总结结构」「报表规则」之类业务化措辞替代。年终总结计划里提到「靠 AI 完成的部分」属于工作方式本身，允许出现。

### 空记录兜底
- 如果没有日志，**只输出**：

```markdown
# {title}

暂无记录。
```

## Type Style

- `week`：强调本周重点进展、已解决问题、阻塞点和下周可延续动作。
- `month`：强调完成模块、修复问题、体验改进、可见产出和月度学习模式。
- `year`：年终总结。抒情开篇，然后依次讲工作、学习、越用越顺手的地方、不足与反思、新一年近期计划。
